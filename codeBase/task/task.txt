## Reinforcement learning behavior:
Initialization: some molecules are initialized in a graph
Action: a trained policy is applied until converged or the designed number of steps reached
Result: 'new' molecules are generated.

## Some ideas:
- from subgraph (molecule) level, the penalizing function will give us a value between 0 to 1: closer to 0 means the action on this molecule tends to break, and closer to 1 means the action on this molecule tend to form new bonds. However, this function does not help us to decide which molecule (subgraph) should the action be taken on.
- This is a problem: We can take n actions, where n could be 1,2,3,....,n, and see what is the result after n actions, then decide the policy gradient. However, how to decide what n should we use?
